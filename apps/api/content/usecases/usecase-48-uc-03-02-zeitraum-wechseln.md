<h1>UC 03/02: Zeitraum wechseln</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-03-kalenderansichten.md">FT (03): Kalenderansichten</a></li></ul>
<h2>Akteur</h2>
<p>Disponent</p>
<h2>Ziel</h2>
<p>Einen anderen Kalenderzeitraum anzeigen.</p>
<h2>Vorbedingungen</h2>
<ul><li>Eine Kalenderansicht ist geöffnet.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur navigiert vor, zurück oder springt auf einen anderen sichtbaren Zeitraum.<br>2. Das System lädt die Termine für den neuen Zeitraum.<br>3. Das System rendert die gewählte Kalenderansicht neu.</p>
<h2>Alternativen</h2>
<p>Keine.</p>
<h2>Ergebnis</h2>
<p>Der gewünschte Zeitraum ist sichtbar.</p>
