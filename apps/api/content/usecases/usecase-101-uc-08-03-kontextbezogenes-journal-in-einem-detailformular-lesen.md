<h1>UC 08/03: Kontextbezogenes Journal in einem Detailformular lesen</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-08-journal-aenderungshistorie.md">FT (08): Journal / Änderungshistorie</a></li></ul>
<h2>Akteur</h2>
<p>Administrator, Disponent</p>
<h2>Ziel</h2>
<p>Änderungen lesen, die einem konkreten Kunden, Projekt oder Termin zugeordnet sind.</p>
<h2>Vorbedingungen</h2>
<ul><li>Ein bestehender Datensatz ist im Detailformular geöffnet.</li><li>Der Akteur besitzt Journal-Leseberechtigung.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur öffnet im Detailformular den Haupttab „Journal“.<br>2. Das System lädt Einträge mit direktem oder abgeleitetem Bezug zum Datensatz.<br>3. Das System zeigt die Einträge absteigend nach Zeit an.</p>
<h2>Alternativen</h2>
<p>Keine.</p>
<h2>Ergebnis</h2>
<p>Die Historie ist im fachlichen Kontext sichtbar.</p>
