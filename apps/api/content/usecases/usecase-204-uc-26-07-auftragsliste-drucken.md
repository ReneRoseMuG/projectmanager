<h1>UC 26/07: Auftragsliste drucken</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-26-auswertungen-und-reports.md">FT (26): Auswertungen und Reports</a></li></ul>
<h2>Akteur</h2>
<p>Disponent, Administrator</p>
<h2>Ziel</h2>
<p>Aus der Auftragsliste eine paginierte Druckausgabe im Querformat DIN A4 erzeugen.</p>
<h2>Vorbedingungen</h2>
<ul><li>Die Auftragsliste wurde erzeugt.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur klickt auf „Auftragsliste drucken“.<br>2. Das System erzeugt eine Druckvorschau anhand der aktuellen Parameter für Zeitraum und Kategorie.<br>3. Das System zeigt die Ausgabe paginiert im Querformat.<br>4. Jede Seite enthält so viele Kacheln wie ohne Umbruch passen.<br>5. Das System verhindert Kachelumbrüche.<br>6. Das System öffnet den Browser-Druckdialog.</p>
<h2>Alternativen</h2>
<ul><li>Keine Einträge vorhanden: Das System erzeugt eine leere Seite mit Hinweis.</li></ul>
<h2>Ergebnis</h2>
<p>Die Auftragsliste kann gedruckt oder als PDF gespeichert werden. Stornierungen und Reklamationen sind vollständig ausgeschlossen.</p>
