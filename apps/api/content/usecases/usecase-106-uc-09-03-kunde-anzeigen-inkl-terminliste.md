<h1>UC 09/03: Kunde anzeigen (inkl. Terminliste)</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-09-kundenverwaltung.md">FT (09): Kundenverwaltung</a></li></ul>
<h2>Akteur</h2>
<p>Disponent, Administrator</p>
<h2>Ziel</h2>
<p>Die vollständige Kundendetailansicht wird angezeigt, einschließlich aller Stammdaten, referenzierten Projekte, direkter Termine (ohne Projekt), projektgebundener Termine (indirekt über Projekte), sowie kundenbezogener Notizen und Anhänge.</p>
<h2>Vorbedingungen</h2>
<ul><li>Der Kunde existiert.</li><li>Der Akteur ist authentifiziert.</li><li>Der Akteur besitzt Leseberechtigung.</li><li>Der Kunde ist aktiv, <strong>ODER</strong> der Akteur ist Administrator (Administratoren können auch inaktive Kunden sehen).</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur wählt einen Kunden aus einer Liste oder über eine Suche.<br>2. Das System prüft:<br>1. Existiert der Kunde?<br>2. Hat der Akteur Leseberechtigung? (Disponenten sehen nur aktive Kunden; Administratoren sehen alle.)<br>3. Falls Checks nicht bestanden: System antwortet mit 404 oder 403.<br>3. Das System lädt den Kundendatensatz (Stammdaten: Name, Kundennummer, Adresse, Telefon).<br>4. Das System lädt alle dem Kunden direkt zugeordneten <strong>Projekte</strong>.<br>1. Das System zeigt die Projektliste an.<br>5. Das System lädt alle dem Kunden zugeordneten <strong>Direkttermine</strong> (Termine ohne Projekt, direkt diesem Kunden zugeordnet).<br>1. Das System zeigt diese als separate Liste „Direkte Termine&quot; an.<br>2. Jeder Direkttermin zeigt: Datum, Uhrzeit (falls vorhanden), Mitarbeiter, Tour (falls zugeordnet).<br>6. Das System lädt alle dem Kunden zugeordneten <strong>Projekttermine</strong> (Termine, die über Projekte diesem Kunden zugeordnet sind).<br>1. Das System kann diese optional nach Projekt gruppieren oder als unified Liste zeigen.<br>2. Jeder Projekttermin zeigt: Datum, Uhrzeit (falls vorhanden), Projekt, Mitarbeiter, Tour (falls zugeordnet).<br>7. Das System lädt alle kundenbezogenen <strong>Notizen</strong>.<br>1. Das System zeigt die Notizenliste an.<br>8. Das System lädt alle kundenbezogenen <strong>Anhänge</strong>.<br>1. Das System zeigt die Anhangsliste an mit Dateinamen und Upload-Zeitstempel.<br>9. Das System zeigt die Kundendetailansicht mit folgenden Bereichen:<br>1. <strong>Stammdaten</strong> (Name, Kundennummer, Adresse, Telefon, Status aktiv/inaktiv)<br>2. <strong>Projektliste</strong> (alle dem Kunden zugeordneten Projekte)<br>3. <strong>Direkte Termine</strong> (Termine ohne Projekt, direkt diesem Kunden zugeordnet)<br>4. <strong>Projekttermine</strong> (Termine über Projekte, optional nach Projekt gruppiert)<br>5. <strong>Notizenliste</strong> (alle kundenbezogenen Notizen)<br>6. <strong>Anhangsliste</strong> (alle kundenbezogenen Anhänge)</p>
<h3><strong>Anzeige- und Query-Regeln</strong></h3>
<ul><li><strong>Rollenabhängige Filterung:</strong> Disponenten erhalten nur aktive Kunden. Administratoren können aktive und inaktive Kunden sehen. Ein Disponent, der einen inaktiven Kunden direkt ansteuert, wird blockiert.</li><li><strong>Terminlisten-Ableitungslogik:</strong> Das System lädt Direkttermine (Termin ohne Projekt, zum Kunden gehörend) und Projekttermine (Termin mit Projekt, Projekt zum Kunden gehörend) separat und zeigt beide an.</li><li><strong>Notizen:</strong> Kundenbezogen und projektunabhängig.</li><li><strong>Anhänge:</strong> Kundenbezogen und projektunabhängig.</li><li><strong>Konsistenzgarantie:</strong> Alle Termine, egal ob direkt oder indirekt, gehören zum gleichen Kunden.</li></ul>
<h2>Alternativen</h2>
<ul><li><strong>Kunde existiert nicht:</strong> System antwortet mit 404.</li><li><strong>Akteur ohne Leseberechtigung:</strong> System blockiert mit 403.</li><li><strong>Kunde ist inaktiv, Akteur ist Disponent:</strong> System blockiert mit 403 oder 404.</li><li><strong>Keine Projekte vorhanden:</strong> Projektliste ist leer oder wird ausgeblendet.</li><li><strong>Keine Direkttermine vorhanden:</strong> Bereich „Direkte Termine&quot; ist leer oder wird ausgeblendet.</li><li><strong>Keine Projekttermine vorhanden:</strong> Bereich „Projekttermine&quot; ist leer oder wird ausgeblendet.</li><li><strong>Keine Notizen vorhanden:</strong> Notizenliste ist leer oder wird ausgeblendet.</li><li><strong>Keine Anhänge vorhanden:</strong> Anhangsliste ist leer oder wird ausgeblendet.</li></ul>
<h2>Ergebnis</h2>
<p>Die Kundendetailansicht ist vollständig und konsistent dargestellt. Es werden keine Daten verändert. Die dargestellten Daten entsprechen dem aktuellen persistenten Zustand. Alle Projekte, Direkttermine, Projekttermine, Notizen und Anhänge sind sichtbar. Disponenten sehen nur aktive Kunden; Administratoren sehen alle. Keine verwaisten oder inkonsistenten Referenzen werden angezeigt.</p>
