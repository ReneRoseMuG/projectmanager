<h1>UC 04/16: Tour-KW blockieren und Termine parken</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-04-tourenplanung.md">FT (04): Tourenplanung</a></li><li>Siehe auch: <a href="../../ft-06-automatische-regeln/use-cases/uc-06-04-termin-auf-parkplatz-setzen.md">UC 06/04: Termin auf Parkplatz setzen</a></li></ul>
<h2>Akteur</h2>
<p>Administrator, Disponent</p>
<h2>Ziel</h2>
<p>Eine Tour-KW bewusst aus der aktiven Wochenplanung nehmen, alle betroffenen nicht stornierten Termine dieser Tour und Kalenderwoche parken und die Tour-KW-Mitarbeiterplanung für diese Woche leeren.</p>
<h2>Vorbedingungen</h2>
<ul><li>Der Akteur ist authentifiziert.</li><li>Der Akteur besitzt Administrator- oder Disponentenrechte.</li><li>Die Tour ist eine regulär planbare Tour.</li><li>Die Tour-KW liegt in einer für den Akteur editierbaren Kalenderwoche.</li><li>Die Systemtour <strong>Parkplatz</strong> und der Zustand <strong>Geparkt</strong> sind verfügbar.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur öffnet eine Tour-KW-Karte im Wochenkalender, im Tourformular oder in der Tour-KW-Wochenplanung.<br>2. Der Akteur wählt die Aktion <strong>Wochenplanung blockieren</strong>.<br>3. Das System prüft Rolle, Tour, Kalenderwoche, Sperrstatus und die erforderlichen Parkplatz-Grundlagen.<br>4. Das System ermittelt die Termine dieser Tour in der betroffenen Kalenderwoche.<br>5. Das System parkt alle betroffenen nicht stornierten Termine über den bestehenden Parkplatz-Workflow aus <a href="../../ft-06-automatische-regeln/use-cases/uc-06-04-termin-auf-parkplatz-setzen.md">UC 06/04</a>.<br>6. Das System entfernt die gespeicherten Tour-KW-Mitarbeiterzuordnungen dieser Tour und Kalenderwoche.<br>7. Das System setzt den Sperrstatus der Tour-KW auf blockiert.<br>8. Das System aktualisiert Wochenkalender, Tourformular, Tour-KW-Wochenplanung, Monitoring und betroffene Terminansichten.</p>
<h2>Alternativen</h2>
<ul><li>Leser löst die Aktion direkt aus: Das System lehnt die Mutation ab.</li><li>Vergangene Tour-KW: Das System lehnt die Mutation als schreibgeschützt ab.</li><li>Parkplatz- oder Abwesenheiten-Tour: Das System bietet keine reguläre Tour-KW-Planung an und lehnt direkte Mutationsaufrufe ab.</li><li>Systemtour <strong>Parkplatz</strong> oder Zustand <strong>Geparkt</strong> fehlt: Das System bricht die Mutation ab und verändert keine Termine.</li><li>Stornierte Termine in der Tour-KW: Das System lässt sie in ihrem bestehenden Zustand und zählt sie nicht als geparkte Termine.</li><li>Bereits geparkte Termine: Das System behandelt sie idempotent und parkt sie nicht erneut.</li></ul>
<h2>Ergebnis</h2>
<p>Die Tour-KW ist blockiert. Nicht stornierte betroffene Termine liegen auf <strong>Parkplatz</strong>, tragen <strong>Geparkt</strong> und besitzen keine Mitarbeiterzuweisungen. Die Tour-KW enthält keine gespeicherten Mitarbeiterzuordnungen mehr. Weitere Mitarbeiteränderungen und Anwenden-Aktionen für diese Tour-KW bleiben gesperrt, bis die Tour-KW wieder freigegeben wird.</p>
