<h1>UC 33/04: Abwesenheit löschen</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-33-abwesenheiten-ueber-interne-personalplanung.md">FT (33): Abwesenheiten über interne Personalplanung</a></li></ul>
<h2>Akteur</h2>
<p>Disponent, Administrator</p>
<h2>Ziel</h2>
<p>Abwesenheit eines Mitarbeiters entfernen</p>
<h2>Vorbedingungen</h2>
<p>Abwesenheit ist vorhanden. Akteur besitzt Disponent- oder Administratorrechte.</p>
<h2>Ablauf</h2>
<p>1. Akteur wählt eine bestehende Abwesenheit im Tab <strong>Abwesenheiten</strong> und bestätigt das Löschen<br>2. System prüft Berechtigung und Version<br>3. System löscht den zugrunde liegenden Termin</p>
<h2>Alternativen</h2>
<p>Versionskonflikt → System meldet Konflikt, Akteur lädt neu</p>
<h2>Ergebnis</h2>
<p>Abwesenheit ist gelöscht. Mitarbeiter ist im Zeitraum wieder verfügbar.</p>
