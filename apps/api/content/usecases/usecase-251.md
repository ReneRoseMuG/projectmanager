<h1>UC 29/02: Mit Google Authenticator einloggen</h1><h2>Akteur</h2><p>Jeder Benutzer (Disponent, Administrator, Reader)</p><h2>Ziel</h2><p>Benutzer meldet sich an, indem er Passwort und 6-stelligen Code eingibt.</p><h2>Vorbedingungen</h2><ul><li>Google Authenticator ist für diesen Benutzer aktiviert.</li><li>Benutzer hat die App mit dem richtigen Geheimnis konfiguriert.</li></ul><h2>Ablauf</h2><ol><li>Benutzer öffnet Login-Seite.</li><li>Benutzer gibt Benutzername/E-Mail und Passwort ein.</li><li>System validiert Benutzername und Passwort.</li><li>System zeigt Eingabefeld für den 6-stelligen Code.</li><li>Benutzer liest den aktuellen Code aus der App ab.</li><li>Benutzer gibt den Code ein.</li><li>System validiert den Code gegen das gespeicherte Geheimnis.</li><li>System erstellt authentifizierte Session.</li><li>Benutzer wird auf Startseite weitergeleitet.</li></ol><h2>Alternativen</h2><ul><li>Passwort falsch → kein Code-Fenster.</li><li>Code falsch → neuer Versuch möglich.</li><li>Code abgelaufen → neuer Code erforderlich.</li><li>Abbruch → Session wird verworfen.</li><li><code>totp_enabled = false</code> → direkter Login ohne Code.</li></ul><h2>Ergebnis</h2><p>Benutzer ist authentifiziert und hat Zugriff auf die Anwendung.</p>
