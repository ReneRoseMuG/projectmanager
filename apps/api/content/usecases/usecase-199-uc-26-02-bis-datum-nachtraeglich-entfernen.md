<h1>UC 26/02: Bis Datum nachträglich entfernen</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-26-auswertungen-und-reports.md">FT (26): Auswertungen und Reports</a></li></ul>
<h2>Akteur</h2>
<p>Disponent, Administrator</p>
<h2>Ziel</h2>
<p>Ein gesetztes Bis Datum entfernen und den Report ohne obere Grenze neu erzeugen.</p>
<h2>Vorbedingungen</h2>
<ul><li>Das Bis Datum ist sichtbar und enthält einen Wert.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur leert das Feld „Bis Datum“.<br>2. Der Akteur klickt auf „Report erzeugen“.<br>3. Das System erzeugt den Report ab dem Von Datum ohne obere Datumsgrenze.</p>
<h2>Alternativen</h2>
<p>Keine.</p>
<h2>Ergebnis</h2>
<p>Der Report zeigt alle passenden Termine ab dem Von Datum ohne Bis Datum.</p>
