<h1>UC 07/05: Backup-Historie einsehen</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-07-automatisierte-datensicherung-und-fallback.md">FT (07): Automatisierte Datensicherung und Fallback</a></li></ul>
<h2>Akteur</h2>
<p>Administrator</p>
<h2>Ziel</h2>
<p>Nachvollziehen aller Backup-Läufe.</p>
<h2>Vorbedingungen</h2>
<ul><li>Administrator ist angemeldet.</li></ul>
<h2>Ablauf</h2>
<ul><li>Admin öffnet Einstellungsbereich.</li><li>Admin wechselt zum Tab „Backups“.</li><li>System zeigt tabellarische Liste aller <code>backup_log</code>Einträge.</li></ul>
<h2>Alternativen</h2>
<ul><li>Keine Logeinträge vorhanden → Leere Liste.</li></ul>
<h2>Ergebnis</h2>
<p>Admin kann Status und Verlauf aller Backups einsehen.</p>
