<h1>UC 03/03: Darstellungsgrad der Wochenkacheln umschalten</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-03-kalenderansichten.md">FT (03): Kalenderansichten</a></li></ul>
<h2>Akteur</h2>
<p>Disponent</p>
<h2>Ziel</h2>
<p>Die Informationsdichte der Terminkacheln in der Wochenansicht anpassen.</p>
<h2>Vorbedingungen</h2>
<ul><li>Der Wochenkalender ist geöffnet.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur wählt im Bereich „Kacheln“ den Darstellungsgrad „Kompakt“, „Standard“ oder „Detail“.<br>2. Das System speichert die Auswahl benutzerspezifisch.<br>3. Das System rendert die Wochenkacheln neu.</p>
<h2>Alternativen</h2>
<p>Keine.</p>
<h2>Ergebnis</h2>
<p>Die Wochenansicht zeigt dieselben Termine mit angepasster Informationsdichte.</p>
