<h1>UC 29/01: 2FA beim Login konfigurieren (erzwungen)</h1><h2>Akteur</h2><p>Jeder Benutzer (Disponent, Administrator, Reader)</p><h2>Ziel</h2><p>Ein Benutzer meldet sich an und wird gezwungen, Google Authenticator zu konfigurieren, weil ein Administrator diese Funktion für den Benutzer aktiviert hat. Nach erfolgreicher Konfiguration und Validierung eines Test-Codes ist der Benutzer eingeloggt.</p><h2>Vorbedingungen</h2><ul><li>Der Benutzer versucht, sich zum ersten Mal anzumelden, nachdem ein Administrator 2FA für ihn aktiviert hat (<code>totp_enabled = true</code> wurde vom Admin gesetzt).</li><li>Der Benutzer hat noch kein Geheimnis konfiguriert (<code>totp_secret = NULL</code>).</li><li>Der Benutzer hat eine TOTP-kompatible App auf seinem Mobilgerät installiert.</li></ul><h2>Ablauf</h2><ol><li>Benutzer öffnet die Anwendung und sieht das Login-Formular.</li><li>Benutzer gibt Email/Benutzername und Passwort ein.</li><li>System validiert Email/Benutzername und Passwort.</li><li>System erkennt, dass 2FA erzwungen ist, aber noch nicht konfiguriert.</li><li>System zeigt einen Konfigurationsbildschirm statt des normalen Logins.</li><li>System generiert ein zufälliges Base32-Geheimnis und zeigt einen QR-Code an.</li><li>System zeigt optional auch die Rohdaten des Geheimnisses als Text.</li><li>Benutzer scannt QR-Code oder gibt Rohdaten manuell ein.</li><li>Benutzer gibt den generierten 6-stelligen Code ein.</li><li>System validiert den Code gegen das Geheimnis.</li><li>System speichert das Geheimnis verschlüsselt in <code>totp_secret</code>.</li><li>System erstellt eine authentifizierte Session.</li><li>Benutzer wird auf die Startseite weitergeleitet.</li></ol><h2>Alternativen</h2><ul><li>Passwort falsch → kein Konfigurationsbildschirm.</li><li>Code-Validierung fehlgeschlagen → Benutzer bleibt auf Konfigurationsbildschirm.</li><li>Code abgelaufen → neuer Code erforderlich.</li><li>Abbruch → Geheimnis wird nicht gespeichert.</li></ul><h2>Ergebnis</h2><p>Das Geheimnis ist verschlüsselt gespeichert. Der Benutzer ist authentifiziert. Zukünftige Logins erfordern Passwort und 6-stelligen Code.</p>
