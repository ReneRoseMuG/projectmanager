<h1>UC 03/05: Monatsübersicht anzeigen</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-03-kalenderansichten.md">FT (03): Kalenderansichten</a></li></ul>
<h2>Akteur</h2>
<p>Disponent</p>
<h2>Ziel</h2>
<p>Einen Monatsbereich verdichtet überblicken.</p>
<h2>Vorbedingungen</h2>
<ul><li>Termine sind im Zeitraum vorhanden oder der Zeitraum kann leer angezeigt werden.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur öffnet die Monatsübersicht.<br>2. Das System lädt die Termine des Monats.<br>3. Das System ordnet Termine je Wochenzeile in Tour-Slots ein.<br>4. Das System zeigt die Monatsübersicht an.</p>
<h2>Alternativen</h2>
<p>Keine.</p>
<h2>Ergebnis</h2>
<p>Der Monatsbereich ist in verdichteter Kalenderform sichtbar.</p>
