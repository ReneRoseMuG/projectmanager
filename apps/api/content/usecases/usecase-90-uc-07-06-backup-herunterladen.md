<h1>UC 07/06: Backup herunterladen</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-07-automatisierte-datensicherung-und-fallback.md">FT (07): Automatisierte Datensicherung und Fallback</a></li></ul>
<h2>Akteur</h2>
<p>Administrator</p>
<h2>Ziel</h2>
<p>Herunterladen eines gespeicherten Backups.</p>
<h2>Vorbedingungen</h2>
<ul><li>Backup-Datei existiert serverseitig.</li></ul>
<h2>Ablauf</h2>
<ul><li>Admin doppelklickt auf einen Eintrag.</li><li>System prüft Berechtigung.</li><li>System liefert Datei über geschützten Endpoint aus.</li></ul>
<h2>Alternativen</h2>
<ul><li>Datei nicht vorhanden → Fehlermeldung anzeigen.</li></ul>
<h2>Ergebnis</h2>
<p>Backup-Datei wird lokal gespeichert.</p>
