<h1>UC 27/03: Komponentenkategorie anlegen (Admin)</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-27-produktverwaltung-und-auftragspositionen.md">FT (27): Produktverwaltung und Auftragspositionen</a></li></ul>
<h2>Akteur</h2>
<p>Administrator</p>
<h2>Ziel</h2>
<p>Eine neue Komponentenkategorie erstellen, um Komponenten zu gruppieren.&lt;br&gt;</p>
<h2>Vorbedingungen</h2>
<ul><li>Der Nutzer ist angemeldet und besitzt die Rolle Administrator.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Administrator öffnet die Komponentenverwaltung.<br>2. Der Administrator navigiert zu „Komponentenkategorien&quot;.<br>3. Der Administrator klickt auf „+ Neue Kategorie&quot;.<br>4. Der Administrator gibt einen eindeutigen Namen ein (z.B. &quot;Wände&quot;, &quot;Heizung&quot;, &quot;Türen&quot;).<br>5. Der Administrator gibt optional eine Beschreibung ein.<br>6. Der Administrator speichert.<br>7. Das System validiert die Eindeutigkeit des Namens.</p>
<h2>Alternativen</h2>
<ul><li>Der Name existiert bereits → Validierungsfehler.</li></ul>
<h2>Ergebnis</h2>
<p>Die Komponentenkategorie existiert und steht beim Anlegen von Komponenten zur Verfügung.&lt;br&gt;</p>
