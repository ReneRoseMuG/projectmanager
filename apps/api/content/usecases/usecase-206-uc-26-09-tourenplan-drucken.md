<h1>UC 26/09: Tourenplan drucken</h1>
<h2>Metadaten</h2>
<ul><li>Feature: <a href="../ft-26-auswertungen-und-reports.md">FT (26): Auswertungen und Reports</a></li></ul>
<h2>Akteur</h2>
<p>Disponent, Administrator</p>
<h2>Ziel</h2>
<p>Aus dem Tourenplan-Report eine Druckausgabe erzeugen.</p>
<h2>Vorbedingungen</h2>
<ul><li>Der Tourenplan wurde erzeugt.</li></ul>
<h2>Ablauf</h2>
<p>1. Der Akteur klickt auf „Tourenplan drucken“.<br>2. Das System öffnet die Druckvorschau.<br>3. Die Kopfzeile enthält den Tournamen.<br>4. Die Fußzeile enthält die Seitennummer.<br>5. Der Akteur wählt optional Hoch- oder Querformat.<br>6. Das System öffnet den Browser-Druckdialog.</p>
<h2>Alternativen</h2>
<ul><li>Keine Einträge vorhanden: Das System erzeugt eine leere Seite mit Hinweis.</li></ul>
<h2>Ergebnis</h2>
<p>Der Tourenplan kann im gewählten Format gedruckt oder als PDF gespeichert werden.</p>
