# Projekt-Kontext — feste Referenzen

Diese Datei hinterlegt die festen Projekt-Manager-Referenzen für dieses Repository. Sie ist versioniert und damit auf jedem Arbeitsplatz (zu Hause wie im Büro) identisch verfügbar, sobald der aktuelle Stand gepullt ist. Maschinenlokales Agent-Memory ist hierfür ungeeignet, weil es nicht zwischen Rechnern geteilt wird.

## Standard-Log-Ziel

| Zweck | Referenz | Name |
|---|---|---|
| Abschluss-Logkommentare für Code-/Fix-Aufträge | `PROJ-3` | Projekt Manager |

Nach jedem abgeschlossenen Auftrag der Klasse 4 oder 5 schreibt der Agent zusätzlich zum dateibasierten Schritt-Log (`agents.md §5`) automatisch einen kurzen, anwenderlesbaren Abschlusskommentar an dieses Projekt. Die verbindliche Regel steht in `agents.md §13.1.1`.

## Wartung

- Ändert sich die feste Projekt-ID, wird ausschließlich diese Tabelle angepasst — die Regel in `agents.md` verweist auf diese Datei und bleibt unverändert.
- Weitere feste Referenzen (z. B. ein zweites Standardprojekt) werden als zusätzliche Zeilen ergänzt.
